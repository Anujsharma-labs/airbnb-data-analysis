# 🏠 Airbnb Data Analysis

An exploratory data analysis and Power BI dashboard project focused on understanding Airbnb listing patterns, pricing, neighbourhood distribution, room types, reviews, and availability.

---

## 📌 Project Overview

This project analyzes Airbnb listing data to identify meaningful patterns and insights using **Python-based Exploratory Data Analysis (EDA)** and **Power BI**.

The analysis explores different aspects of Airbnb listings, including neighbourhood distribution, pricing, room types, reviews, and availability.

The project combines Python for data exploration and visualization with Power BI for creating an interactive analytical dashboard.

---

## 🎯 Objectives

* Understand the distribution of Airbnb listings across different neighbourhoods.
* Analyze listing prices across neighbourhoods and room types.
* Explore the distribution of different room types.
* Analyze review-related patterns.
* Examine listing availability.
* Identify useful patterns and insights from the dataset.
* Present the findings through an interactive Power BI dashboard.
